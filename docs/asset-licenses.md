The model is scaled and repositioned for the scene.

The supplied camera and Eiffel Tower models have no author or license metadata; confirm their redistribution permissions before deploying them publicly. The project explorer does not reproduce employer interfaces. Record the source and permission for every future addition here before launch.

The Paris case study requests only the nine raster tiles currently visible around the Eiffel Tower after the interactive map is loaded. Tiles are not bundled or prefetched; the browser follows the tile server's cache headers. The map displays a visible link to the OpenStreetMap copyright page, which identifies the contributors and the ODbL terms for the underlying map data. Requests use the standard public tile endpoint and must continue to follow its usage policy.
